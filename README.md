**From zero to "the person who actually knows how this works."**

A complete, dependency-ordered curriculum covering programming fundamentals → math → data science →
classical ML → deep learning → transformers → LLMs → RAG → agents & LangGraph → production →
frontier research.

Every resource was verified live on **27 July 2026**, rated **free vs paid**, with an honest verdict
on which to take and why.

## How it's designed to be used

- **Skip tests.** Each phase opens with concrete questions. Answer them all confidently, skip the
  phase. Starting "from zero" costs nothing if you're actually further along.
- **Builds, not just reading.** Every module ends with something you make. Skip the builds and the
  roadmap is worthless.
- **Honest verdicts.** Free vs paid is stated for every topic, with a recommendation. Most of the
  best material in this field is free — the doc says so plainly, and says exactly where it isn't.

## The money question

Total recommended spend across the entire roadmap: **~$270**, up to ~$430 with optional items.

Five books and some GPU credits. Everything else — Karpathy's Zero to Hero, Stanford CS336,
Hugging Face's courses, LangChain Academy, Anthropic Academy, a dozen complete textbooks — is free
and is genuinely the best available at any price.

See the [full accounting](ROADMAP.md#total-spend-the-honest-accounting) for what to buy and what to
never buy.
